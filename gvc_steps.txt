Step 1 - Fill The Drawer (Container Creation with Base Process):
Initiate the 'Fill The Drawer' step by creating a series of 'containers'. Each container is generated through the 'baseProcess', which assigns three key attributes to it:

1. Random Number (randomNumber): This number, randomly selected between 10 and 75, dictates the total count of images that will be assigned to this container. It determines the size of the image array that will be gathered from the 'video_frames' folder.

2. Random Opacity (randomOpacity): Assign a random opacity value between 30% and 70% to each container. This opacity setting will be applied to all images within the container.

3. Random Blend Mode (randomBlendMode): Choose a random blend mode for each container from the following options: multiply, screen, overlay, or soft light (or comparable modes to those found in Adobe software).

These attributes set the foundational parameters for how each container will contribute to the final video compilation, influencing both the visual variety and the blending dynamics of the resulting imagery.

Step 2 - Image Array Creation and Seek and Fill Process (seekAndFill):
This step involves populating each container with images to meet its specific 'randomNumber' requirement, which determines the number of images in the container. The process is as follows:

1. Selecting Initial Images:
• Randomly select a folder within the 'video_frames' directory.
• Within this folder, choose a random starting image.

2. Fulfilling Container Image Count:
• From the starting image, sequentially select subsequent images to add to the container.
• Continue this process until you either reach the end of the folder or fulfill the 'randomNumber' count for the container.

3. Handling Insufficient Images:
• If the number of available images in the folder is less than the 'randomNumber', do the following:
- Count the number of images acquired from this folder.
- Subtract this count from the 'randomNumber' to determine the remaining number of images needed.
- Select another random folder and a random starting image within it.
- Repeat the process of adding subsequent images to the container.
- Continue this cycle - selecting a new folder and starting image, and then adding images - until the total count of images in the container matches the original 'randomNumber'.

4. Completion of Image Array:
• Once the container holds a number of images equal to its assigned 'randomNumber', the process for that container is complete. Each image in this array will also inherit the container's 'randomOpacity' and 'randomBlendMode' settings.
